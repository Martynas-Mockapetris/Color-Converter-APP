# 🎨 React Color Converter

A simple and interactive color converter built with React and Vite. The application allows users to convert colors between RGB and HEX formats, with synchronized inputs and a live color preview.

## ✨ Features

- **RGB to HEX Conversion** — Convert RGB color values into their corresponding HEX representation.
- **HEX to RGB Conversion** — Convert HEX color codes into RGB values.
- **Synchronized Inputs** — Automatically update RGB and HEX values when either format is changed.
- **Live Color Preview** — Instantly preview the selected color through a dynamic background.
- **Input Validation** — Validate HEX color codes before converting them.
- **RGB Value Constraints** — Use individual inputs for red, green, and blue values, with a range of 0–255.

## 🛠️ Technologies Used

- **React** — Component-based UI development.
- **JavaScript (ES6+)** — Color conversion logic, event handling, and dynamic data manipulation.
- **Vite** — Development server and production build tooling.
- **React Hooks** — `useState` for managing RGB and HEX values, and `useEffect` for synchronizing color formats.
- **CSS3** — Application styling and layout.
- **HTML5** — Application structure and input elements.
- **Git & GitHub** — Version control and source code hosting.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Martynas-Mockapetris/Color-Converter-APP.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Color-Converter-APP
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in your terminal, typically `http://localhost:5173`.
